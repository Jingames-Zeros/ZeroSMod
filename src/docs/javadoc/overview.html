This site documents the Zero S methods and hooks exposed to CNPC scripts, plus the CustomNPC+ API they build on. Use the sidebar or the class list for the method reference pages.

Reference Pages

  • ScriptDBCAddonHeatMethods - custom-form heat methods called on player.getDBCPlayer().
  • ScriptDBCPlayerMethods - DBC life, fusion and status-effect methods called on player.getDBCPlayer().
  • ScriptAbilityDomeMethods - typed settings for CNPC+ dome abilities before casting.
  • ScriptEnergyDomeMethods - damage, following, membership and resizing methods for spawned CNPC+ domes.
  • ScriptKiAttackBuilderMethods - destroyer accent methods for NPCDBC IKiAttack configurations.
  • ScriptKiAttackEntityMethods - methods called directly on DBC ki attack entity wrappers.
  • ScriptLivingKiMethods - methods called on NPC/player/living entity wrappers.
  • ScriptPlayerInstantTransmissionMethods - methods called on player wrappers.
  • ScriptPlayerTransformationMethods - custom-form transformation state called on player wrappers.
  • ZSAPI - methods called through the global ZSAPI object.
  • IZeroSEvent.BeginsTransformingEvent - event for beginsTransforming(event).
  • IZeroSEvent.FormDrainEvent - cancellable custom-form Ki drain event for dbcFormDrain(event).
  • IZeroSEvent.WeaponSwingEvent - cancellable weapon hit event for zsWeaponSwing(event).
  • IZeroSEvent.EnergyDomeEnterEvent - event for energyDomeEnter(event).
  • IZeroSEvent.EnergyDomeExitEvent - event for energyDomeExit(event).
  • IZeroSEvent.ActivatedInstantTransmissionEvent - event for activatedInstantTransmission(event).

Parameter Note

On ZSAPI radius methods, origin means the entity used as the middle of the search. For example, ZSAPI.stopKi(npc, 5) stops ki within 5 blocks of that NPC until ZSAPI.releaseKi(npc, 5). Wrapper methods like npc.stopKi(5) do not need this parameter because the wrapper itself is the origin.
